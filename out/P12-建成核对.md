## 建这个项目顺手修掉的工具缺陷（`tools/casegen/`）

1. **`seat/save` 一次传多场次 → 票档跨场次共享**：5 场次 × 5 档会变成 25 个 sku 挂在每个场次下，
   与 B 端 UI 逐场次保存出的规范结构不符；且事后补单场次 `seat/save` 会被平台拒（已有座位图 → 500）。
   → `factory.create_project()` 改为**逐场次保存**并回读校验票档数。
2. **骨架克隆不带年龄限购** → 新项目「18+可购场次」是空壳。→ 新增 `_clone_age_limits()`。
3. **骨架克隆不带 `fixedSaleTime`** → 新项目「未开售场次」实际已开售，`drift --deep` 报
   「未开售时间窗缺失」，未开售负向用例无从覆盖。→ `_build_ticket_price_list()` 补搬该字段
   （这也是生产历史遗留同一问题的根因）。
4. **登记时给 0 元档自动打 `free_fixture`** → 该标签全清单必须唯一，
   会让 `catalog.one(usage="free_fixture")` 抛 `CatalogLookupError`，打断 `test_b_verify` /
   `test_b_refund` / `test_catalog`。→ 已改为不自动打标。
5. `resolve` 默认目标排序新增「避开 `not_started` / `expired` 特殊场次」——
   否则 0 元档会落到「未开售场次」。
