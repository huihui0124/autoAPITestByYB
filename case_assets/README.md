# 用例资产整理目录

这里存放从人工用例 Excel 和现有自动化测试中整理出的派生资产。原始 Excel 仍在 `../haomai-migu/testcase`，这里不保存原始文件副本。

## 文件说明

| 文件 | 作用 |
|---|---|
| `自动化覆盖盘点.md` | 当前仓库自动化覆盖能力的人工说明 |
| `用例自动化映射.csv` | 当前 pytest 自动化用例的机器可读映射表 |
| `人工用例资产汇总.csv` | 从 3 个 Excel 归一后的 2295 条人工用例主表 |
| `人工用例资产盘点.md` | 人工用例资产的数量、优先级、模块分布盘点 |
| `人工用例自动化覆盖对齐.csv` | 人工用例与自动化用例的第一版启发式覆盖对齐 |
| `覆盖对齐v1盘点.md` | 覆盖对齐第一版统计说明 |
| `人工用例自动化覆盖对齐_排除兼容.csv` | 排除兼容性/适配/多端/弱网后的覆盖对齐表 |
| `兼容性用例暂缓清单.csv` | 本轮暂不纳入 release_core 的兼容性相关用例 |
| `覆盖对齐v1盘点_排除兼容.md` | 排除兼容性后的覆盖对齐统计 |
| `release_core候选评审.csv` | 第一版上线核心回归候选评审工作表 |
| `release_core候选评审说明.md` | release_core 候选表的决策口径和下一步说明 |

## 建议使用顺序

1. 查看 `人工用例资产盘点.md` 了解人工资产规模。
2. 查看 `覆盖对齐v1盘点_排除兼容.md` 了解排除兼容后的覆盖缺口。
3. 在 `release_core候选评审.csv` 里评审 `release_core_decision`。
4. 评审完成后，再基于确认结果补 marker、补自动化或整理人工 checklist。
